# Premium 3D Web Creative Development

This skill instructs agents on how to build premium, cinematic, interactive 3D websites using React, WebGL (Three.js/R3F), and modern motion design (GSAP).

## Core Philosophy

Never create a generic AI-generated landing page. Avoid default patterns such as:
- random gradient blobs
- excessive glass cards
- meaningless floating objects
- animations with no narrative purpose

Prioritize:
- visual hierarchy
- composition
- strong typography
- whitespace
- lighting & depth
- storytelling & deliberate interactions

Every visual effect must have a reason.

## Agent Roles
When conceptually dividing work for a complex site, consider these roles:
- **Art Director**: composition, typography, visual hierarchy, consistency.
- **3D Engineer**: Three.js, R3F, Spline integration, lighting, shaders.
- **Motion Engineer**: GSAP, ScrollTrigger, Lenis, choreography, transitions.
- **Performance Engineer**: WebGL performance, bundle optimization, asset optimization.
- **QA Engineer**: browser testing, responsive testing, accessibility checks.

## Project Start Workflow
1. Understand the product & inspect assets.
2. Choose visual direction & design system.
3. Plan page storytelling.
4. Choose Spline vs R3F vs DOM.
5. Plan motion choreography.
6. Implement structure -> 3D -> animation -> responsive behavior.
7. Optimize & run quality gates (QA).
